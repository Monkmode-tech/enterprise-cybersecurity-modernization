# Client

FICBANK

A fictional mid-sized financial institution.

---

# Business Problem

FICBANK engaged a cybersecurity consulting team after multiple security assessments identified weaknesses affecting the organization's overall security posture.

The objective is to transform assessment findings into a practical enterprise cybersecurity modernization strategy.

---

# Previous Assessments

The engagement consisted of four phases.

Phase 1

Vulnerability Assessment

Activities

- Network discovery
- Port scanning
- Service enumeration
- Vulnerability identification

Major Findings

- Exposed SMB
- Exposed RDP
- Exposed SSH
- Weak segmentation
- Administrative interfaces exposed

---

Phase 2

Security Monitoring

Activities

- Log analysis
- Security monitoring
- Event correlation
- SIEM review

Major Findings

- Limited monitoring
- Alerting gaps
- Incomplete visibility

---

Phase 3

Incident Investigation

Activities

- Security event analysis
- Evidence collection
- IOC analysis
- Incident reporting

Major Findings

- Indicators of compromise
- Unauthorized activity
- Need for improved detection

---

Phase 4

Security Modernization

Recommendations

- Zero Trust
- Network segmentation
- Identity and Access Management
- Splunk Enterprise Security
- Endpoint Detection and Response
- Vulnerability Management
- Patch Governance
